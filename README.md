## 8086 Microprocessor System Design

Designed and implemented a microsystem based on the Intel 8086, including memory mapping and peripheral interfacing.

### Features
- 256 KB EPROM (27C2048)
- 64 KB SRAM (62512)
- Serial communication via 8251 (USART)
- Parallel communication via 8255 (PPI)
- 12-key keypad input
- LED control (10 LEDs)
- 7-segment display (6 digits)

### Functionality
- Serial transmit/receive routines
- Parallel output routines
- Keypad scanning
- LED control routines
- Hex character display on 7-segment

### Technologies
- 8086 Assembly
- Low-level hardware interfacing
- Memory & I/O mapping
